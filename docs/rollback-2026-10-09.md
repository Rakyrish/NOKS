reloaded. PostgreSQL/Redis and the shared TLS proxy were not restarted.

## Application rollback

```sh
cd /root/noks
docker compose -f docker-compose.yml -f docs/rollback-2026-10-09.yml up -d --no-deps --no-build backend worker beat frontend
docker compose exec -T nginx nginx -t
docker compose exec -T nginx nginx -s reload
```

The rollback images are tagged `noks-rollback-{frontend,backend,worker,beat}:20261009`.
They are also recoverable from the protected frontend/backend tar archives if
image-store metadata is lost again. Do not prune these images/archives.

**Keep the additive migrations.** New fields have database defaults for old-code
compatibility. Do not reverse migrations or restore the whole database to roll
back code: that would remove later enquiries and grade/URL delivery receipts.

A PostgreSQL notification lock issue was caught in the first production controlled
test. Backend/worker/beat were temporarily rolled back; the original ORM was
verified, the lock was limited to the notification row (`of=("self",)`), and
all 47 backend tests then passed on an isolated PostgreSQL database before final
redeployment. The production persistence/admin/mock-delivery test then passed.

## Optional targeted catalogue rollback

Review any subsequent company edits before applying the original field snapshot.
This command needs the **new** backend image, even if the running code was rolled
back. It changes only the snapshotted product fields and relationships plus three
category descriptions, and preserves enquiry records, images, accounts, view
counters and quote counters.

```sh
cd /root/noks
docker compose run --rm --no-deps -v /root/noks/.work/2026-10-09:/evidence:ro backend python manage.py repair_catalogue_20261009 --restore /evidence/catalogue-production-original.json --apply
```

Preview first by omitting `--apply`. No full database restore is needed.
For proxy rollback, restore the backed-up `nginx.conf`, validate it and reload
only the NOKS nginx **after** switching application containers so static upstream
addresses point at the correct containers.
