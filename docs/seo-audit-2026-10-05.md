# SEO audit — why the site gets no impressions, clicks or inquiries

**Site:** https://chemicals.noksindustrial.com/
**Audited:** 2026-10-05, against `706bf14` plus the working tree
**Method:** live HTTP probes and a full crawl as Googlebot (499 URLs), 8 weeks of
nginx access logs filtered to Google's own IP range (66.249.x, 1,482 requests),
production database queries, and a candidate build of the current code crawled
the same way.

Search Console (`gsc-analyzer` MCP) did not connect this session, so the
Search Console buckets below are reconstructed from Googlebot's real requests.

---

## 1. Root causes, ranked

### 1.1 None of the September 12 SEO fixes ever reached production — CRITICAL

| Container | Built | Last fix commit |
| --- | --- | --- |
| `noks-chemical-frontend-1` | 2026-09-07 | 2026-09-12 |
| `noks-chemical-backend-1` | 2026-09-07 | 2026-09-12 |

Every defect in `seo-audit-before.md` (D1–D20) is still live. Probed today:

- `/products/does-not-exist` → **200**, carrying both `noindex` and `index, follow`,
  with its canonical pointing at the homepage (soft 404)
- 243 of 249 sitemap `lastmod` values = the moment of the request
- 51 titles end in `| NOKS Chemical Division | NOKS Chemical Division`
- catalog migrations 0006–0009 unapplied on the production DB

**And the committed code could not have been deployed as it stood:** the runtime
Docker stage did not copy `src/lib/redirects.mjs`, which `next.config.mjs`
imports, so the new image exited with `ERR_MODULE_NOT_FOUND` on startup.
Fixed in `frontend/Dockerfile`.

### 1.2 The parent site competes for the same products and never links here — CRITICAL

`noksindustrial.com` (WordPress/WooCommerce, Yoast) has an
`industrial-chemicals` category with about 71 chemical products, titled
"… in Kenya, Uganda, Tanzania". **32 of our 182 products have a direct
equivalent there** (acetone, caustic soda flakes, calcium hypochlorite,
calcium carbonate, ethyl acetate, hydrogen peroxide…).

The homepage of the parent site contains **zero links** to
`chemicals.noksindustrial.com`. The subdomain was first crawled on 2026-08-10, so it
is about 8 weeks old, with no inbound authority, and it is competing with the
company's own older, established domain for the same queries. Google picks one
result per company per query, and it picks the parent.

This cannot be fixed in this repo. See §4.

### 1.3 Inquiries are generated but never delivered — CRITICAL

- `EMAIL_BACKEND=django.core.mail.backends.console.EmailBackend`: every quote
  and inquiry notification is printed to the worker log, never emailed
- `SALES_NOTIFICATION_EMAIL=sales@noks.co.ke`, `DEFAULT_FROM_EMAIL=…@noks.co.ke`,
  and the published support address `technical@noks.co.ke`: **`noks.co.ke` has no
  DNS at all** (no A record, no MX record)
- Forms work: `POST /api/v1/inquiries/` validates and saves. Lifetime totals
  are 1 `QuoteRequest` (2026-09-30), 0 `Inquiry`, across 6,614 product views

Fixed in `.env`: notifications now go to `info@noksindustrial.com` (Cloudflare
MX). **Still needed:** SMTP credentials and `EMAIL_BACKEND=…smtp.EmailBackend`.

### 1.4 Titles did not match how buyers search — HIGH

168 of 182 products are AI-drafted, and their `meta_title` reads like a spec line
("Caustic Soda Flakes NaOH 1310-73-2 Industrial Grade"). **Only 14 of 182
product titles mentioned Kenya.** B2B chemical queries in this market are
"<product> supplier Kenya", "<product> price Nairobi". 74 titles also exceeded
Google's display width.

Fixed: `productTitle()` in `lib/metadata.ts` keeps a CMS title that names a
place, and otherwise uses "<Name> Supplier in Kenya". On the candidate build,
182 of 182 product titles carry the market.

### 1.5 Low crawl demand

Googlebot fetches about 30–40 URLs/day and `robots.txt` (446 fetches) more often
than products. 234 of its 1,482 requests went to malformed Cloudinary paths
(§2). This is a consequence of 1.1–1.4 rather than a separate cause: Google
crawls more where it finds unique, consistent, linked content.

## 2. Search Console buckets — sources and fixes

### "Page with redirect" (172 real Googlebot 3xx)

| Source | Count | Fix |
| --- | --- | --- |
| `/https://res.cloudinary.com/…`: the D1 broken JSON-LD image URL, collapsed by Next.js and answered with a 308 to `/https:/res…`, which then 404s | 117 | D1 fixed in code; **new nginx rule** sends 301 straight to the real Cloudinary asset (tested: 301 → 200 image/jpeg) |
| `/products/<slug>/` trailing slash, external, no referrer | ~55 | Correct behaviour: a single-hop 308 to the canonical URL. Expected to stay in this bucket; it is not an error |

### "Not found (404)" (128 real Googlebot 404s)

| Source | Fix |
| --- | --- |
| The Cloudinary paths above, after the 308 | nginx rule above |
| `/favicon.ico` (10 requests). The only icon was the 1300×409 wordmark, and Google only shows square favicons | Added `src/app/favicon.ico`, `icon.png` (192px) and `apple-icon.png`, cropped from the logo mark |
| `/terms` (1 request) | There is no terms page, so a genuine 404 is the correct response |

The 182 soft-404 risk (missing product slug → 200) becomes a real 404 once the
current code is deployed. Verified on the candidate build.

### "Alternate page with proper canonical tag" (188 on production)

This bucket is informational: Google found a duplicate and honoured the
canonical. It is not an error. The volume came from:

| Source | Count | Fix |
| --- | --- | --- |
| `/quote?product=<slug>` on every product card and product page | 182 | `rel="nofollow"` on all 6 link sites; the page is `noindex, follow` → `/quote` |
| Footer (sitewide) linking `/products?category=…`, 3 links pointing at the empty `specialty-chemicals` | 8 | Footer now links clean `/categories/<slug>` routes, verified against the DB |
| Knowledge topic chips, industry "browse" buttons | 16 | Genuine filter UI, `noindex, follow`: correct as is |

Candidate build: 188 → 24 alternate-canonical URLs, all of them intentional.

## 4. Off-repo actions (owner)

1. **Deploy** (§6). Nothing else matters until this is done.
2. **Resolve the parent-site overlap.** Pick one home per product:
   - Recommended: on `noksindustrial.com`, 301 each overlapping chemical product
     to its `chemicals.` equivalent, and link the "Chemicals" menu item to the
     subdomain. Alternatively, set a cross-domain canonical on those 32 pages
   - At minimum, add a prominent link from the parent homepage and nav. This is
     the single cheapest authority signal available
3. **Email:** set SMTP credentials (`EMAIL_HOST_USER/PASSWORD`) and switch
   `EMAIL_BACKEND` to `django.core.mail.backends.smtp.EmailBackend`, then send a
   test inquiry.
4. **Search Console:** add `chemicals.noksindustrial.com` as its own property
   if it is only verified as a domain property. Resubmit `sitemap.xml`. Use
   "Validate fix" on the Page-with-redirect, 404 and soft-404 reports. Request
   indexing for the homepage, `/catalogue` and the top 10 categories.
5. **Google Business Profile** for the Nairobi address, linking to this site.
6. **Analytics:** `NEXT_PUBLIC_GA_MEASUREMENT_ID` is empty, so there is no way to
   measure traffic or conversions.
7. **Content:** 25 duplicate-CAS clusters await review (`duplicate-listings.md`).
   Rewrite the AI-drafted descriptions of the top 20 products with real
   packaging, MOQ, lead time and Kenyan use cases.

## 5. Known, not changed

- Homepage title repeats the brand ("NOKS Chemical Division — … | NOKS Chemical
  Division"), because `NEXT_PUBLIC_SEO_TITLE` starts with the brand and the
  root layout appends it. Low impact; adjust the env value if wanted.
- `/terms` and `/privacy` pages don't exist. Trust pages help B2B conversion.


(`noks_migration_check`) and applied cleanly.
